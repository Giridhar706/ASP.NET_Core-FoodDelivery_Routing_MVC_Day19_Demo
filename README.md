# Online Food Delivery Portal - ASP.NET Core MVC

## Project Overview

This project is developed using ASP.NET Core MVC to demonstrate routing concepts in a real-world Online Food Delivery Portal scenario.

The application includes:

- URL Routing
- Custom Routes
- Attribute Routing
- Route Constraints
- SEO Friendly URLs
- User Navigation

---

## Features

✅ Default Routing  
✅ Custom SEO Friendly Routes  
✅ Attribute Routing  
✅ Route Constraints Validation
